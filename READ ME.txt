MASS INSTALLER

A little tool I made with AI to quickly install or update useful Windows apps together through WinGet locally on 64-bit Windows.

INSTALL

1. Download the latest release ZIP.
2. Extract the complete folder.
3. Double-click Installer.bat.
4. Press Y once to accept the Terms and bundled Tool License and approve setup.
5. Leave the setup window open until every check passes.
6. Double-click the Mass Installer shortcut created in the folder.

Keep the full extracted folder path at 72 characters or fewer so Windows can install the private packages reliably.
Before downloading, run winget --version in PowerShell or Command Prompt. Update Microsoft App Installer first if WinGet is older than v1.29.280.

USE

1. Search or browse the app catalog.
2. Select the apps you want.
3. Review the selection.
4. Choose Install.
5. Leave Mass Installer open while the queue finishes.

SETUP DETAILS

Setup keeps official Python 3.14.7, PySide6-Essentials, settings, and app-specific files private to this folder. It verifies the official WinGet source without resetting or rewriting it. It does not require administrator access, change PATH, or install global Python packages. Downloaded runtime archives are verified before use.

Setup creates and validates a folder-local Mass Installer shortcut that starts the app directly with this folder's private runtime. Run Installer.bat again to repair setup or after moving the complete folder. Saved selections and logs are preserved.

PRIVACY AND REMOVAL

The app has no telemetry, analytics, advertisements, accounts, or uploads. Network requests occur only for setup and the installs you start. Review logs before sharing because they can contain package names, installer output, and local folder paths.

To remove this tool, close it and delete the extracted folder. This removes its folder-local shortcut, private runtime, dependencies, settings, logs, and app files. Apps installed through it remain installed.

TROUBLESHOOTING

If setup stops, the window immediately shows the failed check and a short
"How to fix it" instruction. The same guidance is saved in setup.log.
Correct the problem and run Installer.bat again. Success is shown only after
the dependencies, offline self-tests, and shortcut all pass. Keep the complete
extracted folder together.

If a trusted WinGet is just outdated, open a normal PowerShell or Command
Prompt and run: winget upgrade Microsoft.AppInstaller
If WinGet is missing or the command fails, install or update App Installer
from Microsoft Store: https://apps.microsoft.com/detail/9nblggh4nns1
If App Installer fails trust validation, repair it in Windows Settings before
updating. Reopen the terminal, check winget --version, and run setup again.
Microsoft guidance:
https://learn.microsoft.com/en-us/windows/msix/app-installer/install-update-app-installer
Setup checks WinGet before downloading private Python packages and again
before success.
